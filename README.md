# Aplikasi Presensi & Kesibukan Departemen Sharia Entrepreneurship (SharE)

Aplikasi web modern untuk manajemen kesibukan harian, presensi/izin, dan rekapitulasi otomatis ketersediaan anggota Departemen Sharia Entrepreneurship.

## Fitur Utama:
- **12 Bulan Lengkap (Januari - Desember)**: Manajemen jadwal kesibukan harian sepanjang tahun.
- **Pilihan Hari & Sesi Jam**: Sesi Pagi (09-11), Siang (13-15), Sore (16-17), dan Malam (19-21).
- **Manajemen Anggota Otomatis**: Fitur Tambah & Hapus anggota yang langsung menyesuaikan tabel matriks.
- **Export to Spreadsheet**: Mengunduh rekapitulasi bulanan & tahunan langsung dalam format `.csv` (Excel / Google Sheets).
- **Presensi & Form Izin**: Fitur pelaporan halangan hadir beserta alasannya.

## Cara Deploy ke Vercel via GitHub:
1. Extract file zip ini di komputer kamu.
2. Push seluruh folder ke GitHub repository kamu.
3. Buka [Vercel.com](https://vercel.com) dan Import repository tersebut.
4. Klik **Deploy**.
